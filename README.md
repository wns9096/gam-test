## 내가 만든 것 — 🌎 지진은 얼마나 자주  (by wns9096)

골격에 들어 있던 지진 주제를 **지우고 원본부터 다시 열어** 만들었습니다.
원본은 USGS 지진 카탈로그(2000~2024년, 규모 5.5 이상, 12,336건)입니다.
값은 한 줄도 손으로 옮겨 적지 않았습니다 — `tools/build_topics.py` 의 식이 답입니다.

**세기 전에 걸러낸 것**

1. **「지진 목록」에 지진이 아닌 것이 2건 섞여 있었습니다** — 핵실험 1, 화산 분화 1.
   `type` 을 안 거르면 2017년 북한 핵실험이 지진 통계에 들어갑니다.
2. **「한반도 주변」이라고 위·경도 네모를 그렸더니 그 안 지진 123건 중 89건(72.4%)이
   일본 것이었습니다.** 상자(북위 33~39.5 · 동경 124~132)에 규슈 북부와 쓰시마가
   들어 있습니다. 네모에 이름을 붙이면 그 이름대로 센 줄로 압니다.
3. **깊이의 28.2%가 「정확히 10.0km」 였습니다**(33.0km 가 5.4%). 그렇게 잰 것이
   아니라, 깊이를 정하기 어려울 때 그 값에 고정해 놓고 계산한 것입니다.
4. **같은 지진의 규모가 기관마다 달라 순서까지 바뀝니다.** 이 데이터에서는 2017년
   포항 5.5 가 2016년 경주 5.4 보다 크지만, 기상청 발표는 경주 5.8 · 포항 5.4 로
   반대입니다.

**문항 다섯은 골격의 다섯과 묻는 것도 답도 전부 다릅니다.**

| | 골격 | 내 것 |
|---|---|---|
| 1 | 규모 5.5 이상 연 몇 번 (493.4건) | 평균 몇 시간에 한 번 (17.8시간) |
| 2 | 규모 7.0 이상 연 몇 번 (14.8건) | 70km 보다 깊은 것 몇 % (18.6%) |
| 3 | 가장 자주 기록된 나라 (인도네시아) | 규모 한 칸당 몇 배 (10배쯤) |
| 4 | 가장 큰 지진의 규모 (9.1) | 상자 안 일본 비중 (70%가 넘는다) |
| 5 | 한반도 주변 건수 (50~150건) | 지진이 아닌 것 둘 (화산 분화·핵실험) |

골격의 4번 「가장 큰 지진의 규모」는 **답할 수 없는 질문**이라 버렸습니다. 같은 지진도
기관마다 규모가 달라 순서까지 바뀝니다(USGS 는 포항 5.5 > 경주 5.4, 기상청은 경주 5.8 >
포항 5.4). 「가장 큰」은 기관을 붙이지 않으면 성립하지 않아서, 문항에서 빼고 한계에
적었습니다.

**답을 다른 길로 다시 세어 대조했습니다** (`tools/검산.py`). 생성한 코드를 불러 쓰면
같은 식을 두 번 돌리는 것이라 대조가 아니므로, `build_topics.py` 를 임포트하지 않고
데이터 파일만 다시 읽습니다. 세는 길도 일부러 다르게 잡았습니다 —
날수는 한 번 빼는 대신 **해마다 세어 더하고**(윤년 7일), 깊이는 깊은 쪽 대신 **얕은
쪽을 세어 빼고**, 나라 비중은 **나라별 합이 전체인지**로 확인합니다.

**나머지 아홉 주제는 골격의 계산입니다.** 제가 확인한 것은 「`data/raw/` 에서 나온
값이다」(재생성 대조)까지이고, 계산식이 옳은지는 지진만 확인했습니다.
그 구분은 `tools/문항검사.py` 출력 마지막 줄에도 적혀 있습니다.

### 아홉 주제에서 찾아 고친 것

- **맞힐 수 없는 문항이 하나 있었습니다.** `w2` 「한국보다 더 오래 일하는 나라는
  129개국 중 몇 개일까요?」 는 정답이 72인데 슬라이더 위끝이 **60** 으로 손에
  박혀 있었습니다. 끝까지 밀어도 12 이 모자랍니다. 데이터가 갱신되며 한국 순위가
  밀렸는데 범위는 안 따라온 것입니다. 위끝을 데이터에서 나오게 고쳤습니다.
- **슬라이더에 손도 안 대고 제출하면 점수가 나왔습니다.** 기본값이 범위 한가운데라
  환율 `x5` 는 **100점**, 환율 주제는 평균 65점이었습니다(객관식을 전부 0점으로 쳐도).
  추측 게임에서 안 움직인 것은 추측이 아니므로, 한 번은 움직여야 넘어가게 했습니다.
- **「이 데이터의 한계」가 넷은 비어 있고 셋은 한 줄이었습니다.** 원본을 열어 확인한
  것만 채웠습니다. 예 — 환율 데이터는 1999-01-04 부터라 **1997~98년 외환위기가 아예
  없고**(그래서 「26년 최고」는 「1999년 이후 최고」입니다), 달력 9,494일 중 6,658일
  (70%)만 있습니다.
- **폰에서 슬라이더가 잡히는 높이가 8px 였습니다.** 동그란 손잡이는 34px 라 커
  보이는데 요소 자체는 트랙과 같은 8px 였습니다. 44px 로 늘렸습니다.
- **촌평이 조용히 안 뜨는 구조였습니다.** 골격의 기본 모델 `gemini-2.5-flash` 는
  모델 목록에는 있는데 호출하면 404 이고, 이 함수는 무엇이 실패하든
  `{"comment": null}` 을 돌려주므로 화면은 멀쩡한 채 촌평만 영영 안 뜹니다.
  부를 수 있는 모델을 직접 불러 보고 고르고, 실패 까닭을 응답과 로그에 남깁니다.

## 확인하는 법

```
python tools/점검.py                 안전·내 문항·앱 구조          14
python tools/검산.py                 지진을 다른 길로 다시 세기     12
python tools/문항검사.py --재생성     열 주제 전부 + 재생성 대조     차단 0 · 경고 12
python tools/브라우저시험.py          진짜 브라우저로 폰 너비에서    18
python tools/배포점검.py              배포된 주소를 대고            19
```

`브라우저시험` 은 `pip install playwright && playwright install chromium` 이 필요하고,
서버를 스스로 띄웁니다. `배포점검` 은 배포 주소를 열어 봅니다 — **로컬 통과는 배포
통과가 아닙니다.** 실제로 로컬은 촌평이 1.1초에 오는데 배포본은 `{"comment": null}`
이었습니다.

`GET /api/comment` 는 `{ok, key, fp, ws, model}` 을 돌려줍니다. `fp` 는 키의 sha256
앞 8자리라 **키를 보지 않고** 배포에 들어간 키가 내 손의 키와 같은지 견줄 수 있습니다.

## 데이터가 오는 길

```
   [내 노트북]                                   [인터넷]

   tools/fetch_all.py      공개 데이터 6곳에서 받기 (키·로그인 없음)
        ↓  data/raw/  약 19MB   ← git 에도 배포에도 올라가지 않습니다
   tools/build_topics.py   원본에서 문항 계산
        ↓
   topics/*.json  약 40KB  ← 이것만 올라갑니다
```

원본을 브라우저로 보내서 거기서 평균을 내는 게 아닙니다. **평균은 내 노트북에서 미리
내고, 그 결과만 싣습니다.** 그래서 폰에서 즉시 뜹니다.

## Gemini 촌평 (선택)

**키가 없으면 촌평만 빠지고 나머지는 그대로 돕니다.** 로컬(`python -m http.server`)에서는
서버리스 함수가 돌지 않으므로 촌평 자리가 나타나지 않습니다. 정상입니다.

`api/comment.py` 맨 위의 `MODEL` 은 AI Studio 에서 지금 쓸 수 있는 이름으로 맞춥니다.
직접 불러 본 결과(2026-09-19)는 그 파일 주석에 적어 두었습니다 —
`gemini-2.5-flash` 는 **404**, `gemini-3.5-flash` 는 빈 응답,
`gemini-flash-lite-latest` 는 1.4초에 정상입니다.

## 이 데이터를 믿을 때의 한계

각 주제의 결과 화면 맨 아래에 **「이 데이터의 한계」** 상자가 있습니다. 공개 데이터라고
맞는 데이터가 아닙니다.

**골격 README 에 적혀 있던 것** (골격을 만든 사람의 기록입니다)

- **ERA5 재분석**의 서울 역대 최고기온은 37.6도지만, **기상청 관측 기록은 39.6도**입니다
- World Bank의 '모든 나라' 목록에는 **유럽연합·고소득국 같은 집계치가 78개** 섞여 있습니다
- 공휴일 API의 2025년 한국 목록에는 제헌절이 공휴일로 들어 있었습니다 — 공휴일 데이터는
  제도 변경에 민감해 주제에서 뺐습니다

**내가 원본을 열어 확인한 것**

- 환율은 1999-01-04 부터라 **1997~98년 외환위기가 데이터에 아예 없습니다.** 달력
  9,494일 중 6,658일(70%)뿐이고 주말·공휴일은 빠집니다
- 기대수명은 그해 사망률이 평생 이어진다고 놓고 만든 값이라 **뚝 떨어졌다 돌아옵니다** —
  세계 평균 2019년 72.6세 → 2021년 70.9세 → 2023년 73.2세
- 인터넷 사용률은 2023년에 **217곳 중 181곳만** 값을 냈고, 세계 평균 69.2%는 나라별
  평균이 아니라 **인구로 가중한** 집계값입니다
- 출산율 순위의 분모 217곳에는 **나라가 아닌 곳**도 들어 있습니다(1위가 마카오)
- 지진 목록에 **지진이 아닌 것이 2건** 섞여 있었습니다 (핵실험 · 화산 분화)
